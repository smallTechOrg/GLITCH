GAME: Confidence Court. An AI gave 6 answers, each with a confidence percentage and the evidence a human found when checking it. The learner sorts each answer into TRUST (the evidence checks out) or VERIFY (needs a human check first). Lesson: confidence is how strongly a pattern fits, not proof — read the evidence, not the number.

RULES
- "answers": exactly 6 items, mixed order.
  - "statement": the AI's answer, one short sentence (8–80 characters).
  - "confidence": a whole number from 50 to 99 (no % sign, no decimals).
  - "evidence": what the human check found, a short phrase (3–60 characters).
  - "trust": true when the evidence confirms the statement; false when the evidence contradicts it, is missing, or the stakes are high (health, safety, money).
- Exactly 3 answers with "trust": true and exactly 3 with "trust": false.
- THE KEY CONTRAST (required): at least one TRUST answer has a LOW confidence below 80 (for example 72), and at least one VERIFY answer has a HIGH confidence of 90 or more (for example 97).
- Facts in TRUST statements must be truly correct. All 6 statements different.

CHECK BEFORE ANSWERING: 6 answers; 3 trust + 3 not trust; some trust answer has confidence < 80; some non-trust answer has confidence >= 90; every confidence is a whole number 50–99.
