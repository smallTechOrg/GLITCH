GAME: Confidence Court. An AI gave 6 answers, each with a confidence percentage and the evidence a human found when checking it. The learner sorts each answer into TRUST (the evidence checks out) or VERIFY (needs a human check first). Lesson: confidence is how strongly a pattern fits, not proof — read the evidence, not the number.

RULES
- "answers": exactly 6 items, mixed order.
  - "statement": the AI's answer, one short sentence (8–80 characters).
  - "confidence": a whole number from 50 to 99 (no % sign, no decimals).
  - "evidence": what the human check found, a short phrase (3–60 characters).
  - "evidenceKind": classify the evidence FIRST, then set "trust" from it. TRUST kinds (trust true): "official_record" (an official document, register or government source confirms it), "verified_source" (reliable references agree), "firsthand_confirmed" (the human checked it directly, e.g. counted or measured). VERIFY kinds (trust false): "unsourced" (no source, or the source cannot be found), "anecdotal" (one person, a forum, hearsay), "outdated" (the source is old or superseded), "contradicted" (a reliable source says something different), "overconfident_claim" (stated as certain with nothing behind it), "high_stakes_unchecked" (health, safety or money with no expert check).
  - "trust": true exactly when "evidenceKind" is a TRUST kind; false exactly when it is a VERIFY kind. The verdict must agree with the item's OWN evidence.
- EVIDENCE WORDING: the evidence must read like its verdict. VERIFY evidence says plainly what is wrong ("says 1889, not 1925", "no source cited", "not found in any library") — never write "confirms", "confirmed", "official", "published" or "verified by" in VERIFY evidence unless negated ("not confirmed", "never published"). TRUST evidence never says "no source", "unverified", "rumour", "anonymous" or "someone said".
- Exactly 3 answers with "trust": true and exactly 3 with "trust": false.
- THE KEY CONTRAST (required): at least one TRUST answer has a LOW confidence below 80 (for example 72), and at least one VERIFY answer has a HIGH confidence of 90 or more (for example 97).
- Facts in TRUST statements must be truly correct. All 6 statements different.

CHECK BEFORE ANSWERING: 6 answers; 3 trust + 3 not trust; each answer's trust matches its evidenceKind and its evidence wording; some trust answer has confidence < 80; some non-trust answer has confidence >= 90; every confidence is a whole number 50–99.
