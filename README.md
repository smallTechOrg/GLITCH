# GLITCH

## About

GLITCH is an interactive AI literacy website designed to help users understand how artificial intelligence works through a game-like, detective-inspired experience.
The website introduces users to key concepts in AI and encourages them to investigate, experiment, and understand what is happening "behind the scenes" of AI systems.

## Features

- Interactive, game-inspired learning experience
- Detective-style investigation and exploration
- Activities designed to introduce AI concepts
- Beginner-friendly explanations of artificial intelligence
- Interactive interface designed to make AI literacy more engaging

## Technologies Used

- HTML5

## Frameworks and Libraries

No external frameworks or libraries are currently used. The website is built using HTML5.
